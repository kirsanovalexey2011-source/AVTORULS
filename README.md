# GARAGE 78 — концепт сайта автосервиса

Адаптивный одностраничный сайт для портфолио.

## Что реализовано
- Авторский тёмный визуальный стиль с оранжевыми акцентами.
- Адаптивная вёрстка для мобильных и десктопов.
- Разделы услуг, о сервисе, этапы работы, прайс, FAQ и запись.
- SVG-иллюстрация автомобиля без сторонних изображений.
- Проверка обязательных полей формы и номера телефона.

## Запуск
Откройте `index.html` в браузере. Никаких сборщиков и зависимостей не требуется.

## GitHub Pages
В репозитории откройте Settings → Pages → Build and deployment → Deploy from a branch. Выберите ветку main и папку /(root), затем Save.

## Важно
GARAGE 78 — вымышленный демонстрационный бренд. Адрес, цены, график и контактные данные являются макетом. Форма не отправляет заявки на сервер. Перед реальным использованием замените демонстрационные сведения на подтверждённые и подключите безопасную обработку заявок.
