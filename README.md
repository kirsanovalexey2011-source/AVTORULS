# GARAGE 78 — концепт сайта автосервиса

Адаптивный демонстрационный сайт автосервиса для портфолио. Проект опубликован на GitHub Pages и не требует сборщика или установки зависимостей.

## Что внутри

- Современная визуальная система: тёплый светлый фон, графитовые секции и лаймовый акцент.
- Отдельные файлы HTML, CSS и JavaScript.
- Адаптивная навигация для мобильных устройств.
- Переключатель светлой и тёмной темы с сохранением выбора в браузере.
- Карточки услуг, которые автоматически выбирают нужное направление в форме записи.
- Форма с проверкой полей, российской маской телефона и подготовкой текста заявки.
- Кнопка копирования подготовленной заявки. Данные не передаются на сервер и не сохраняются.
- FAQ-аккордеон, подсветка активного пункта меню, плавное появление секций, кнопка возврата наверх.
- SEO-описание, Open Graph-метаданные и SVG favicon.

## Локальный запуск

Откройте `index.html` в браузере. Для локальной разработки можно запустить любой простой статический сервер из корня проекта, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и каталог `/(root)`, затем сохраните настройки.

## Перед реальным запуском

GARAGE 78 — вымышленный демонстрационный бренд, а не реальный клиент или действующий автосервис. Санкт-Петербург указан как часть концепции. Цены приведены исключительно как примеры; график, адрес, телефон, список марок и условия обслуживания не подтверждены.

Форма проверяет введённые данные и собирает текст заявки только в браузере. Она не отправляет сообщения в Telegram, на почту или на сервер. Для реального приёма заявок нужно подключить backend или безопасную серверную функцию. Токены Telegram-бота и другие секреты нельзя помещать в клиентский JavaScript.
